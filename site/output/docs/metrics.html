# Metric definitions

Definition version 1.0. Windows end before the as_of timestamp. The monthly window is the last calendar month that has already ended, so a run on 15 October uses September. Rates are fractions from 0 to 1. Counts are published even when they are zero. Rates, medians, and concentration use a sample floor of 5 and are withheld, with flag insufficient_data, when the population is smaller.

Headcount metrics do not use that floor.

A pull request or commit is counted in every Java component it touches. When it touches more than one, it is also counted under cross-cutting. Repository and ecosystem totals still count that change once. Component shares therefore overlap and must not be added together.

Project-wide mail and the ecosystem release metrics are not assigned to a module.
